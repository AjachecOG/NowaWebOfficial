# Audyt SEO i widoczności — NowaWeb (nowaweb.pl)

**Data:** 2026-08-02  
**Cel:** wyjaśnić brak widoczności w Google oraz porównać z konkurencją typu NOVA WEB (`nova-web.pl`).  
**Zakres:** live https://nowaweb.pl, kod w repo, sygnały indeksacji (Google / Bing / DuckDuckGo), porównanie on-page.

---

## Werdykt (TL;DR)

**Strona nie pojawia się w wynikach Google, bo najpewniej w ogóle nie jest jeszcze zindeksowana** — nie dlatego, że „źle wygląda” albo że Google preferuje AI-slop.

Potwierdzone sygnały:

| Test | Wynik |
|---|---|
| `site:nowaweb.pl` (Google via search API) | **brak wyników** |
| DuckDuckGo `site:nowaweb.pl` | **„No results found”** |
| Wayback Machine `nowaweb.pl` | **brak snapshotów** |
| Certyfikat TLS Let’s Encrypt | wystawiony **2026-07-28** |
| SOA DNS (`2026072802`) | domena/DNS ustawione ok. **28.07.2026** |
| Sitemap lastmod | **2026-07-28** |

Strona jest więc **świeża (~5 dni)**. Nowe domeny bez Search Console, bez linków i bez historii zwykle wchodzą do indeksu w ciągu **3–14 dni** (homepage), a pełniejsza widoczność to **tygodnie** — pod warunkiem, że Google w ogóle dostanie sygnał do crawlnięcia ([Submit a New Site to Google — 2026](https://aitoolsguidebook.com/en/articles/submit-new-site-to-google-2026/), [Easy Guides Hub](https://www.easyguideshub.com/2026/01/how-long-does-google-take-to-index-new.html)).

Techniczne fundamenty SEO (robots, sitemap, canonical, index/follow, OG, JSON-LD) **są już na miejscu**. To nie jest awaria `noindex`.

## 1. Co działa dobrze (fundamenty)

- Live HTTPS, `www` → apex 301, Netlify HSTS.
- `robots.txt`: `Allow: /` + `Sitemap: https://nowaweb.pl/sitemap-index.xml`.
- Sitemap z 5 URL-ami (home, kontakt, 3 strony prawne); `/dziekujemy` i 404 wykluczone.
- Meta: `index, follow`, canonical, Open Graph, Twitter card, OG image 1200×630.
- `lang="pl"`, tytuł i description obecne.
- JSON-LD: Organization + WebSite + ProfessionalService.
- Statyczny HTML (Astro) — treść jest w źródle, nie tylko w JS.
- Googlebot dostaje `200` i te same meta co użytkownik.

## 2. Główne powody braku widoczności

### P0 — Brak discovery / brak indeksacji (nie problem kodu)

1. **Brak (lub niepotwierdzone) Google Search Console** — w HTML nie ma `google-site-verification`; bez GSC Google często „nie wie”, że strona istnieje.
2. **Brak backlinków i historii domeny** — zero archive.org, zero cytowań w SERP-ach pod brandem `nowaweb.pl`.
3. **Kolizja marki** — zapytanie „NowaWeb” w Google zwraca głównie niemieckie [nowaweb.de](https://www.nowaweb.de/) i profile LinkedIn/Tracxn, nie Twoją domenę.
4. **Świeżość** — launch ~28.07.2026; bez ręcznego „Request indexing” czekanie jest loterią.

### P1 — Za mało „paliwa” rankingowego nawet po indeksacji

1. **Cienka architektura treści:** 1 landing + kontakt + strony prawne. Brak bloga, FAQ (do tej pory), landingów usługowych, lokalnych stron (np. Wrocław).
2. **~700 słów** widocznego tekstu na homepage — mało na konkurencyjne frazy typu „tworzenie stron internetowych”.
3. **Title/H1 nie celują w frazy komercyjne:**
   - Title: „NowaWeb | Strony firmowe bez WordPressa”
   - H1: „Profesjonalny design nie jest luksusem”
   - Fraza „tworzenie stron” = **0** wystąpień w treści; „strony internetowe” = 2; „SEO” = 0.
4. **Usługi na froncie kart to same obrazki** — nazwy usług są w HTML (tył karty), ale sygnał wizualny/UX jest słabszy; nie jest to blokada crawla, ale słabsza czytelność oferty.
5. **Brak lokalnego SEO:** brak Google Business Profile, brak LocalBusiness schema z geo, słabe podkreślenie Wrocławia poza stopką.

### P2 — Drobne techniczne / higiena

- Linki wewnętrzne bez trailing slash (`/kontakt`) przy canonicalach ze slash (`/kontakt/`) — Netlify 301, OK, ale marnuje crawl budget.
- Logo w JSON-LD = OG image (nie osobny plik logo).
- Brak skip-linka (a11y).
- Brak IndexNow / Bing Webmaster.
- Brak analytics (świadomie) — bez GSC nie ma też danych o crawlach.

## 3. Porównanie z NOVA WEB (`nova-web.pl`) — „dlaczego slop się pokazuje?”

### Co ma konkurent (on-page)

| Element | NowaWeb | NOVA WEB (`nova-web.pl`) |
|---|---|---|
| Title | Brand + „bez WordPressa” | **„Tworzenie stron internetowych”** (fraza head) |
| Description | Brandowa, wąska | Keyword-heavy: małe firmy, AI, ceny, wycena |
| FAQ | Brak (przed tą iteracją) | Duża sekcja FAQ |
| Cennik | Brak | Transparentne ceny |
| Opinie | Brak | Sekcja opinii (**placeholder „Jan Kowalski”**) |
| Sitemap | 5 URL | 1 URL (tylko home) |
| TLS | od 28.07.2026 | od **16.07.2026** (~12 dni wcześniej) |
| Hosting | Netlify | Hostinger/LiteSpeed |

Konkurent wygląda jak generyczny AI landing: fake/placeholder testimonials, „0+ projektów”, agresywne keyword stuffing w title/meta. To **nie jest jakość**, którą Google „lubi” długoterminowo — ale:

1. **Title z główną frazą komercyjną** zwiększa szansę na branded + partial matches.
2. **Więcej sekcji odpowiadających na intencję** (cena, FAQ, usługi po nazwie).
3. **Starszy o ~2 tygodnie** certyfikat / deploy.

### Ważne zastrzeżenie

`site:nova-web.pl` też nie zwracało wyników w tych samych testach (DuckDuckGo: no results). Część „widoczności Nova/NOVA”, którą widzisz, to najpewniej **inne marki**:

- [nova.waw.pl](https://nova.waw.pl/) — rankinguje na „tworzenie stron”, ma Fixly, opinie, historię.
- [novaweb.cz](https://www.novaweb.cz/tvorba-webovych-stranek), [novaweb.ro](https://novaweb.ro/) — zagraniczne agencje.
- [nowaweb.de](https://www.nowaweb.de/) — zabiera brand „NowaWeb”.

Czyli: **nie porównujesz się z lepszym SEO-engine, tylko z chaosem podobnych nazw + starszymi graczami**, a świeży `nova-web.pl` też dopiero walczy o indeks.

## 5. Plan działań (priorytety)

### Natychmiast (ops — poza kodem)

1. **Google Search Console** — właściwość Domain `nowaweb.pl`, weryfikacja DNS TXT u dhosting.
2. Submit sitemap: `https://nowaweb.pl/sitemap-index.xml`.
3. URL Inspection → **Request indexing** dla `/` i `/kontakt/`.
4. To samo w **Bing Webmaster Tools** (+ IndexNow opcjonalnie).
5. **Google Business Profile** (Wrocław / Revela) — nazwa, kategoria „Web designer” / „Website designer”, link do nowaweb.pl.
6. 3–5 realnych cytowań: profil firmy, katalogi B2B, portfolio klientów z linkiem, LinkedIn firmy.

### Krótki termin (kod — część wdrożona w tej PR)

- Lepszy title/description z frazą „tworzenie stron”.
- FAQ + `FAQPage` schema.
- Bogatszy JSON-LD (WebPage, lepsze logo, sameAs placeholder).
- Trailing slash w linkach wewnętrznych.
- Skip link.
- Wsparcie `PUBLIC_GOOGLE_SITE_VERIFICATION`.

### Średni termin (treść / architektura)

1. Landingi usług: `/strony-firmowe/`, `/landing-page/`, `/odswiezenie-strony/`.
2. 1 artykuł/tydzień na blogu pod long-tail (np. „strona firmowa bez WordPressa”, „ile kosztuje strona firmowa 2026”).
3. Case studies z prawdziwymi wynikami (nie same screenshoty).
4. Sekcja cen / widełek (nawet „od …”) — konkurencja to ma, klienci i Google to lubią.
5. Nie kopiować slopu: **prawdziwe opinie** albo zero opinii.
